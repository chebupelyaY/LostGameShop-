# LostGameShop

Конкурсная работа по верстке интерфейса пользователя.

## Страницы
- `index.html` — главная, темная тема (по умолчанию)
- `index_light.html` — главная, светлая тема
- `login.html` — вход
- `register.html` — регистрация
- `profile.html` — личный кабинет

## Требования
- HTML + CSS без фреймворков
- Mobile-first, контрольные точки 360 / 768 / 1920 px
- БЭМ-именование классов
- Семантическая разметка и комментарии

## Git
В репозитории присутствует история из минимум трех осмысленных коммитов.


## Медиа из конкурсного задания
Использованы предоставленные logo.svg, game_01.jpg–game_04.jpg, точная цветовая палитра из colors.txt и данные игр/пользователя/истории покупок из content.txt.
